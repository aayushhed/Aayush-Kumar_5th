 
**[FUNCTIONAL AND NON FUNCTIONAL REQUIREMENTS]**

**[BACK OF THE ENEVELOPE STATEMENT]**

**[DESIGN-ARCHITECTURE]**


FUNCTIONAL REQUIREMENT:
                ---> WHAT THE USER CAN DO ON THE PLATFORM


NON-FUNCTIONAL REQUIREMENT:
                ---> SYSTEM PERFORMANCE
                ---> LATENCY, LOAD CAPABILITY, RESPONSE TIME.
                ---> QUERY PER SECOND
                ---> DAILY ACTIVE USERS CAPABILITIES
                ---> CONSISTENCY (DATA SHOULD BE SAME EVERYWHERE IN THE FILE)---|
                ---> AVAILABILITY                                               |
                ---> RELIABILITY (NO DATA LOSS WHEN QUERY FAIL)-----------------|
                ---> SECURITY                                       
                ---> MAINTAINIBILITY



EXAMPLE:---
            FOR A MESSENGAR APP  WHAT ARE THE FUNCTIONAL AND NON FUNCTIONAL  REQUIREMENTS


            FUNCTIONAL REQU:--                                  NON-FUNCTIONAL REQU:--
                        1. LOGIN                                                1. CONSISTENCY
                        2. LOGOUT                                               2. LOW LATENCY
                        3. MESSAGE SEND                                         3. END 2 END ENCRYPTED
                        4. MESSAGE RECIEVE                                      4. LOAD CAPABLE (SCALIBILITY)
                        5. SEARCH                                               5. RELIABILITY
                        6. BLOCK                                                6. STORAGE
                        7. GROUP CHATS                                          7. CACHE MEMORY
                        8. VOICE, VIDEO CALLS                                   8. AVAILABILITY HIGH
                                                                                9. EASY TO MAINTAIN
                                                                               10. NUMBER OF SESSIONS AT A TIME
                                                                               11. COMPACTABILITY
