# LOAD BALANCING

TYPES:
        1. LAYER 4   (TRANSPORTATION)
        2. LAYER 7   (APPLICATION)

# LAYER 4:
    Works at TCP/UDP level.

It mainly looks at:

Source IP
Destination IP
Source port
Destination port
TCP/UDP protocol

It doesn't understand the actual HTTP request.
IT IS FASTER THAN LAYER 7.


# LAYER 7:

Works at the HTTP/HTTPS level.

It can understand things like:

URL/path
HTTP method
Headers
Cookies
Hostname
Query parameters

SMART LOAD BALANCING( OPEN THE ENTIRE REQUEST SO SLIGHTLY SLOW THAN LAYER 4)



# ALGORITHM FOR LOAD BALANCING:
            1. ROUND ROBIN: 
                    Sends requests to servers one by one.

                            Request 1 → Server 1
                            Request 2 → Server 2
                            Request 3 → Server 3
                            Request 4 → Server 1

Best for: Servers with roughly equal capacity.

            2. LEAST CONNECTION:
            Send traffic to the server having the fewest active connections.

                          S1 → 10 connections
                          S2 → 5 connections   ← New request
                          S3 → 8 connections

                          New request → S2

Best for: Requests with varying processing times.

            3.IP HASHING:
            Uses the client's IP to determine the server.

            Client A → Hash(IP) → Server 2
            Client A → Hash(IP) → Server 2

            Same client generally goes to the same server.

Best for: Session persistence/sticky sessions.

            4.WEIGHTED ROUND ROBIN:
            Servers get different weights based on their capacity.

            Server 1 → Weight 3
            Server 2 → Weight 1

S1 → S1 → S1 → S2 → S1 → S1 → S1 → S2


# HEALTH CHECK

    A health check is a mechanism used by a load balancer to determine whether a backend server is healthy and able to handle requests.
